# Reference policy

- `source/`: user-provided visual references. They are research inputs, not redistributable game assets.
- `generated/`: project-specific style frames generated during design exploration. They are direction boards, not automatically production-ready sprites or textures.

Use references to discuss camera, palette, material, motion, contrast, and mood. Do not trace or reproduce protected characters, exact silhouettes, logos, UI, or scene compositions. Record adopted visual decisions in `docs/VISUAL_BIBLE.md` instead of relying on a private interpretation of an image.
