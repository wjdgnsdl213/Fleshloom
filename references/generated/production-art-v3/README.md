# FLESHLOOM production art v3

Generated on 2026-08-12 with the built-in image generation tool for the P5
presentation pass. The existing runtime Drifter was the subject/composition
reference; the approved gameplay styleframe supplied only mood, material,
lighting, and gameplay-scale readability.

## Armored Drifter

The new variant preserves the hunched Drifter pose, asymmetric arms, wet dark
biomass, and cyan chest organ. Six large overlapping ivory shell plates alter
the silhouette so the two-capture rule remains readable without a health bar.
The runtime displays this bitmap only while the shell is intact. Peeling swaps
back to the exposed Drifter body, adds a short stagger deformation, emits bone
shards, and uses a distinct dry shell-break audio cue.

The built-in tool generated one opaque subject on a flat `#00ff00` chroma-key
background with no floor, shadow, UI, text, logo, watermark, weapon, or metal
armor. The installed imagegen chroma-removal helper used border sampling, soft
matte, thresholds 12/220, and despill. The result contains 961,370 transparent
pixels and 13,072 partially transparent edge pixels out of 1,572,528 pixels.
