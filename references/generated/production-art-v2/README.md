# FLESHLOOM production art v2

Generated on 2026-08-12 with the built-in image generation tool. The approved
`references/generated/loop-gameplay-styleframe-v1.png` supplied camera, mood,
material density, and palette. The existing Drifter supplied render fidelity
and source-up sprite orientation. Elite Husk also served as a layering
reference for Warden.

Every source was requested as one opaque top-down 3/4 character on a perfectly
flat `#00ff00` chroma background, with no shadow, floor, text, UI, logo, or
watermark. The installed imagegen chroma-removal helper produced the runtime
alpha PNGs; procedural rendering remains the load-failure fallback.

## Prompt set

- **Rusher:** spearhead/wedge silhouette; compressed predatory legs; two long
  charge-aligned stabbing forelimbs; ivory spear crown; one restrained cyan
  research core.
- **Watcher:** low tripod surveillance organism; dominant eye/fan silhouette;
  paired ribbed ivory sensor vanes; central cyan optic; small projectile duct.
- **Cutter:** asymmetric stalking parasite; two opposed living scissor limbs,
  one long hook and one counter-blade; exposed tendon; small protected cyan
  organ.
- **Mimic:** one creature built from nearly mirrored half-bodies; central seam,
  paired skull plates, four reflected limbs, and twin balanced cyan organs.
- **Elite Husk:** massive four-limbed brute with an outer ivory rib cage and a
  second tendon membrane; armored silhouette designed to read as two layers.
- **Warden Prototype:** huge central containment organism with exactly two
  loopable cutter arms, two peelable shell plates, one arterial core, and two
  cyan control nodes forming the final triangular objective.

Shared constraints: original FLESHLOOM anatomy; source subject faces straight
up; charcoal/bruised flesh, ivory bone, muted tendon, restricted cyan, and red
only for Warden's core; no clothing, conventional weapons, metal armor, cute
cellular forms, or copied reference identities.
