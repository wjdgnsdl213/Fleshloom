# Game Design — v0.2

Status: foundation lock · 2026-08-11  
Title: **FLESHLOOM** (confirmed 2026-08-11)

## One-sentence pitch

격리 도시를 달리는 기생 생명체가 자신의 몸에서 뽑아낸 살아 있는 선으로 괴물을 에워싸 분해하고, 훔친 특성과 영구 변이를 조합해 진화하는 10–12분 탑다운 액션 로그라이트.

## Design pillars

1. **Move to attack** — 공격 버튼으로 탄을 쏘지 않는다. 위험 속에서 어떤 궤적을 그릴지가 전투다.
2. **Readable predation** — 닻 → 궤적 → 폐쇄 → 수축 → 분해 → 흡수의 인과가 한눈에 읽힌다.
3. **Temporary appetite, permanent build** — 지금 흡수할 적은 전술적 선택이고, 레벨업 변이는 한 판의 빌드 선택이다.
4. **Immediate success, later mastery** — 첫 30초에는 작은 적 한 마리를 쉽게 감싸며, 후반에는 절단·다중 포획·보스 부위전으로 깊어진다.

## Core play loop

1. 이동하며 적의 무리와 공격 패턴을 읽는다.
2. 루프 입력을 한 번 누르면 현재 위치에 **생체 닻**이 고정된다.
3. 방향 입력으로 계속 이동하면 본체 뒤로 **살아 있는 연결선**이 펼쳐진다.
4. 루프 입력을 다시 누르면 현재 위치와 닻이 즉시 연결되어 루프가 닫힌다.
5. 유효한 루프는 안쪽 적을 압축·분해한다. 너무 작거나 자가 교차가 심한 실패 루프는 회수된다.
6. 포획 보상으로 HP/생체량, XP, 적 종별 임프린트 후보를 얻는다.
7. XP가 차면 일시 정지된 3택 변이 화면에서 이번 런의 영구 강화를 고른다.
8. 웨이브를 돌파하고 실험체 보스를 분해하면 엔딩, HP가 0이면 결과 화면 후 즉시 재시작한다.

## Input contract

### Desktop

- 이동: 방향키 또는 WASD. 대각선 속도는 정규화한다.
- 루프 기본값: `Space`로 시작하고 다시 `Space`로 폐쇄하는 토글 방식.
- 입력 옵션: `Space` 홀드 후 릴리스 방식도 유지한다.
- 접근성 옵션: 자동 닫힘 강도, 화면 흔들림, 플래시 강도.

### Touch / pointer

- 왼쪽 가상 스틱 또는 드래그로 이동 의도를 만든다.
- 오른쪽 루프 영역을 탭해 닻을 심고, 다시 탭해 닫는다. 홀드/릴리스도 선택 옵션으로 제공한다.
- 데스크톱과 모바일은 서로 다른 게임 규칙을 갖지 않고 동일한 `InputIntent`를 만든다.

### Non-negotiable behavior

- 루프 중에도 본체는 항상 이동한다.
- 닻 근처 또는 자기 궤적 근처로 돌아오면 시각적 자석 효과와 함께 폐쇄점을 보정한다.
- 초반에는 적이 루프 선을 자르지 않는다. 첫 성공 경험 뒤부터 방해를 가르친다.

## Loop validity and assistance

초기 튜닝값이며 `src/config`에서 조정한다.

- 최소 샘플 간격: 8–12 px
- 닻 자동 스냅 반경: 24 px
- 자기 궤적 자동 스냅 반경: 18 px
- 최소 유효 면적: 플레이어 몸체 면적의 약 2배
- 너무 짧은 탭: 공격 실패로 벌주지 않고 닻을 즉시 회수
- 자가 교차: 첫 교차점까지의 가장 명확한 폐곡선을 우선 후보로 사용
- 폐쇄 직전 유효 영역을 반투명으로 미리 보여 준다.

## Combat and damage

- 일반 공격은 없다. 적을 죽이는 행위는 유효 루프 포획뿐이다.
- 소형 적은 기본적으로 한 번의 포획으로 분해된다.
- 엘리트는 안정도 또는 노출 부위를 갖고, 여러 번의 루프나 특정 공격 텔레그래프 직후 포획을 요구한다.
- 보스는 머리/팔/핵 같은 부위별 포획 단계를 갖는다. 단순히 HP가 큰 잡몹으로 만들지 않는다.
- 적의 몸체, 투사체, 돌진에 맞으면 HP가 감소하고 짧은 무적 시간이 생긴다.
- 절단형 공격이 활성 루프 선에 닿으면 해당 루프가 끊기고 짧은 경직/생체량 손실이 발생한다. 첫 3분 이후에만 본격 등장한다.
- 피격 직후에도 이동 입력은 유지한다. 조작권 박탈은 짧고 명확해야 한다.

## Capture rewards

한 번의 루프가 여러 적을 잡았을 때 자동으로 능력을 갈아끼우지 않는다.

- **XP:** 잡힌 모든 적의 값을 합산한다.
- **회복/생체량:** 잡힌 모든 적의 값을 합산하되 한 루프당 회복 상한을 둔다.
- **임프린트 후보:** 포획한 종의 생체량 비중과 희귀도를 계산해 최대 2개만 제시한다.
- **현재 임프린트 유지:** 아무것도 고르지 않거나 `Keep`을 고르면 남은 시간이 유지된다.
- **교체:** 새 후보를 고를 때만 현재 임프린트가 바뀌고 지속 시간이 새로 시작한다.
- 선택 UI는 전투를 완전히 끊지 않는 짧은 슬로모션으로 시작하되, 플레이 테스트에서 인지 부담이 크면 포획 후 안전 구간 선택으로 바꾼다.

## Progression model

### Temporary imprints — moment-to-moment tactics

| 계열 | 공급 적 | 기본 효과 | 전술적 이유 |
| --- | --- | --- | --- |
| Blade | 절단체 | 폐쇄 시 바깥쪽 칼날 파동 | 밀집하지 않은 적 견제 |
| Spike | 돌진체 | 수축 순간 중심 가시 폭발 | 큰 적 안정도 파괴 |
| Nerve | 감시체 | 닻 설치 시 주변 적 둔화 | 안전한 큰 고리 설계 |
| Symmetry | 분열체 | 반대 방향 보조 궤적 1개 | 다중 포획과 최종 진화 예고 |

임프린트는 약 20–35초 지속하는 방향으로 시작한다. 적을 계속 흡수해야 하지만 원하지 않는 교체는 강요하지 않는다.

### Permanent mutations — run build

- 경험치 레벨업마다 3개 중 1개 선택.
- 초기 목표: 9종, 각 2–3랭크.
- 축: 루프 범위/지속, 폐쇄 속도/수축, 회복/방어, 임프린트 지속, 다중 궤적.
- 흡수 이력은 특정 변이의 등장 확률을 높이거나 상위 카드를 해금할 수 있으나 선택을 강제하지 않는다.
- 네 핵심 계열을 충분히 성장시키면 **Apex: Fourfold Hunt**가 등장한다. 본체 포함 네 방향의 궤적이 짧은 시간 대칭으로 전개된다.

## Initial enemy roster

1. **Drifter:** 느리게 접근하는 첫 포획 교재.
2. **Rusher:** 직선 텔레그래프 후 돌진; Spike 공급원.
3. **Watcher:** 시야선을 고정한 뒤 신경 투사체 발사; Nerve 공급원.
4. **Cutter:** 루프 선을 노리고 절단 돌진; Blade 공급원. 3분 이후 등장.
5. **Mimic:** 이동 방향을 반사해 압박; Symmetry 공급원.
6. **Elite Husk:** 두 부위를 차례로 노출하는 엘리트.
7. **Boss / Warden Prototype:** 팔 절단 → 외피 포획 → 핵 폐쇄의 3단계 전투.

## Run structure

- 0:00–0:30: 이동, 닻, 첫 포획. 실패해도 바로 다시 시도할 안전 공간.
- 0:30–3:00: 기본 적 2종, 첫 임프린트, 첫 레벨업. 심사위원이 핵심 재미를 반드시 경험하는 구간.
- 3:00–7:00: Cutter와 복합 웨이브, 빌드 선택의 의미가 드러나는 구간.
- 7:00–9:00: 엘리트와 대형 포획, Apex 가능성 노출.
- 9:00–12:00: 보스, 짧은 엔딩, 결과와 즉시 재시작.

## Contest-sized definition of done

- 타이틀, 30초 이내 온보딩, 완주 가능한 런, 보스, 엔딩, 결과, 재시작.
- 일반 적 5종, 엘리트 1종, 보스 1종.
- 임프린트 4종, 영구 변이 약 9종, 대표 Apex 1종.
- 키보드와 터치 입력, 음량/화면 효과 접근성 옵션.
- 한 개의 완성도 높은 도시 구역을 시간·날씨·침식 변화로 재구성한다.

## Open play-test questions

- 토글 기본값이 첫 포획 성공률을 높이는가, 홀드 옵션을 찾고 이해할 수 있는가?
- 유효 루프 최소 면적과 스냅 반경이 초보자에게 충분히 관대한가?
- 임프린트 후보 선택이 전투 리듬을 깨는가?
- 포획 수축 연출이 1초 안에 통쾌함과 정보 전달을 모두 달성하는가?
