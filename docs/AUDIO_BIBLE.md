# Audio Bible

## Direction

음악은 영웅적 액션보다 격리 구역의 압박과 생체 리듬을 강조한다. 핵심 사운드는 총격이 아니라 **팽팽해지는 신경선과 닫히는 포획막**이다.

## Music layers

- Base: 빗소리, 환풍기, 먼 경보음, 낮은 드론.
- Pulse: 적 밀도와 함께 들어오는 불규칙 심박/타악.
- Hunt: 유효 루프를 만들고 있을 때만 얇게 상승하는 장력 레이어.
- Apex: 네 방향 진화 시 추가되는 왜곡된 코러스와 넓은 저역.
- Boss: 기존 재료를 더 빠르게 재배열해 한 세계의 음악처럼 유지한다.

초기 구현은 Web Audio 기반 레이어 제어로 충분하다. 실제 음원 제작 전에도 필터 노이즈와 간단한 합성음으로 타이밍을 검증한다.

M1 상태: `PlaygroundAudio`가 사용자 입력 이후 Web Audio로 닻과 폐쇄 준비를 알리고, 성공 시 밝은 폐쇄 파열 → 두 겹의 저역 수축 → 조직 분리 → 상승 흡수음을 약 0.5초에 걸쳐 합성한다. 실패는 훨씬 약한 하강음으로 분리한다. 이는 타이밍과 정보 계층을 검증하는 임시 사운드이며 최종 음원이 아니다.

## Essential SFX

1. 닻 설치 — 짧은 골편 클릭 + 젖은 접착음.
2. 루프 장력 — 길이와 위험도에 따라 피치가 올라가는 지속음.
3. 스냅 가능 — 과하지 않은 두 번의 신경 펄스.
4. 폐쇄 — 단단한 저역 임팩트.
5. 수축/분해 — 안쪽으로 빨려드는 역방향 질감 + 건조한 조직 파열.
6. 흡수 — 본체로 이동하는 방향감 있는 펄스.
7. 피격/절단 — 폐쇄음과 혼동되지 않는 날카로운 단절음.
8. 레벨업/Apex — 생체음 위에 유일하게 명확한 조성감을 부여.

## Mix rules

- 루프 유효화와 적 텔레그래프는 음악보다 항상 앞에 온다.
- 큰 루프가 더 큰 저역과 긴 잔향을 가지되 연속 포획에서 뭉개지지 않게 제한한다.
- 화면 밖 공격은 위치 단서를 준다.
- Master/Music/SFX 개별 음량과 음소거를 제공한다.
- 반복 청취 피로를 줄이기 위해 핵심 파열음은 최소 4개 변형과 피치 변주를 둔다.
